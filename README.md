# 🚚 RoutedCargo Plugin

> Плагин для серверов Minecraft (Spigot / Paper API), добавляющий динамический ивент «Маршрутный груз» с ценным лутом, транспортировкой и PVP/PVE-механиками.

![Java](https://img.shields.io/badge/Java-17%2B-orange?style=for-the-badge&logo=openjdk)
![PaperMC](https://img.shields.io/badge/PaperMC-API-blue?style=for-the-badge)

---

## 🌟 Игровой процесс и возможности

* 📦 **Динамический ивент:** На карте по расписанию или команде админа спавнится ценный маршрутный груз.
* 🛣 **Маршруты и контрольные точки:** Груз перемещается в открытом мире по заданным условиям.
* ⚔️ **PVP / PVE Борьба:** Игроки и кланы могут сопровождать груз для получения награды или сражаться за него.
* 🎁 **Кастомизация лута:** Гибкая настройка наград, выпадающих при успешной доставке.
* ⚡ **Оптимизация:** Асинхронные таски и минимальная нагрузка на поток сервера (TPS).

---

## 🛠 Технологический стек

* **Language:** Java 17
* **API:** Paper / Spigot API
* **Build Tool:** Maven
* **Architecture:** Custom Event System, Task Scheduling

---

## 📝 Команды и описание

| Команда | Описание |
| :--- | :--- |
| `/routedcargo start` | Принудительно запустить ивент с грузом
| `/routedcargo stop` | Отменить текущий ивент
| `/routedcargo status` | Узнать состояние ивента
| `/routedcargo reload` | Перезагрузить конфигурацию плагина
